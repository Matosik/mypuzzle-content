# Контент игры «Мой Пазл»

Этот репозиторий — бесплатный хостинг на GitHub Pages для игры «Мой Пазл»:

- `missions.json` — расписание «Миссии недели» (игра скачивает его при запуске);
- `img/` — картинки миссий;
- `levels/levels.json` и `levels/<страна>/` — пакеты новых уровней (новые страны и места без обновления игры);
- `privacy.html` — политика конфиденциальности (ссылка для карточки в RuStore);
- `check.html` — проверка расписания миссий, `levels.html` — проверка пакета уровней.

Адреса после публикации:

- миссии: https://matosik.github.io/mypuzzle-content/missions.json
- политика: https://matosik.github.io/mypuzzle-content/privacy.html
- проверка миссий: https://matosik.github.io/mypuzzle-content/check.html
- проверка уровней: https://matosik.github.io/mypuzzle-content/levels.html

Обновлять игру в RuStore ради новой миссии или новых уровней **не нужно**: игроки увидят их при следующем запуске игры с интернетом.

## Как добавить новую миссию (раз в неделю, ~5 минут)

1. **Картинка.** Горизонтальное фото 4:3 (например 1600×1200), JPG до ~500 КБ, без надписей и водяных знаков.
   Только свои фото или с лицензией на коммерческое использование.
   На странице репозитория: папка `img` → **Add file → Upload files** → перетащи файл → **Commit changes**.
   Имя файла — латиницей, например `w44.jpg`.
2. **Расписание.** Открой `missions.json` → значок ✏️ (Edit) → добавь в конец списка новую миссию
   (не забудь запятую после предыдущей `}`) → **Commit changes**:

   ```json
   {
     "id": "2026-w44",
     "start": "2026-10-26T00:00:00+03:00",
     "end": "2026-11-02T00:00:00+03:00",
     "title": "Название миссии",
     "description": "Одна короткая фраза для игрока.",
     "image": "img/w44.jpg",
     "pieces": 64,
     "rewardXp": 200
   }
   ```
3. **Проверка.** Через 1–5 минут открой `check.html` (адрес выше). Там видно, какая миссия идёт сейчас, есть ли
   ошибки в файле и когда расписание закончится.

### Поля миссии

| Поле | Что писать |
|---|---|
| `id` | уникальный код, удобно «год-неделя»: `2026-w44` |
| `start`, `end` | начало и конец, московское время `+03:00`; `end` одной миссии = `start` следующей |
| `title`, `description` | название и короткое описание для игрока |
| `image` | путь к картинке: `img/имя.jpg` |
| `pieces` | число деталей: 4–300 (для миссии хорошо 48–100) |
| `rewardXp` | опыт за первое прохождение (монеты +100 игра добавит сама) |

### Советы

- Можно расписать миссии сразу на месяц вперёд — игра сама покажет нужную по датам.
- Если ошибиться в файле (лишняя запятая и т. п.), игра не сломается: игроки увидят прошлое расписание. Исправь и проверь на `check.html`.
- Старые миссии можно не удалять — закончившиеся игра просто не показывает.
- `minAppVersion` в начале файла — минимальная версия игры. Если поднять его выше версии у игроков, в игре появится кнопка «Обнови игру в RuStore».

## Как добавить новые уровни без обновления игры

В игре 164 встроенных уровня. Всё, что лежит в `levels/levels.json`, игра добавляет **после 164-го уровня**:
новые главы (поездки в страны) встают в конец карты, между ними игра сама вставляет уровни-повторы.
Страна может быть новой (Вьетнам) или уже знакомой (вторая поездка в Россию).

1. **Фото.** Требования те же, что у миссий: горизонтальное 4:3, JPG до ~500 КБ, без надписей, со своими правами.
   Клади в папку страны: `levels/<код страны>/<номер>.jpg`, например `levels/vietnam/01.jpg` или `levels/russia/11.jpg`.
   Какой номер свободен, подсказывает страница `levels.html` («Следующие свободные имена файлов»).
2. **Описание.** Открой `levels/levels.json` → ✏️ Edit → добавь главу → **Commit changes**.
   Образец целиком — в `levels/example.json`, можно скопировать оттуда:

   ```json
   {
     "countries": {
       "vietnam": { "name": "Вьетнам", "flag": "🇻🇳", "colors": ["#c53030", "#ecc94b", "#c53030"] }
     },
     "chapters": [
       {
         "country": "vietnam",
         "places": [
           { "image": "vietnam/01.jpg", "city": "Халонг", "name": "Бухта Халонг", "emoji": "⛵",
             "about": "Почти 2000 известняковых островов в изумрудном заливе — объект ЮНЕСКО." }
         ]
       }
     ]
   }
   ```
3. **Проверка.** Через 1–5 минут открой `levels.html`: там видно все новые главы с фото и ошибки, если есть.

### Поля

| Поле | Что писать |
|---|---|
| `countries` | только **новые** страны: код (латиницей, например `vietnam`) → название, флаг-эмодзи и 2–3 цвета для заглушки. Уже встроенные страны (`russia`, `france`, `japan` и др.) описывать не нужно |
| `chapters` | список поездок по порядку; в главе обычно 5 мест (можно меньше или больше) |
| `country` | код страны главы |
| `image` | путь к фото относительно папки `levels/`: `vietnam/01.jpg` |
| `city`, `name` | город или регион и название места |
| `emoji` | значок места на карте и в коллекции (необязательно) |
| `about` | 1–2 предложения о месте — показываются под собранной картиной |

### Важно

- **Имя файла — это ключ места** (`vietnam/01.jpg` → место `vietnam-01`): по нему игра хранит прогресс игроков. После выпуска не переименовывай фото и не меняй порядок глав — дописывай новые главы в конец списка.
- Фото можно заменить на лучшее с тем же именем — игроки, у которых старое уже скачано, его сохранят, новые скачают новое.
- Если ошибиться в `levels.json`, игра не сломается: игроки продолжат с прошлым набором уровней. Исправь и проверь на `levels.html`.
- Фото нового уровня скачивается, когда игрок до него дошёл, и потом хранится на телефоне. Без интернета новый уровень не откроется — игра попросит подключиться.

## Политика конфиденциальности

Данные разработчика (ИП Богачев М. И., ИНН, ОГРНИП) и почта для связи mat.yes1994@yandex.ru уже вписаны. Если почта сменится — поправь её в `privacy.html` (два места) и в `index.html`.
Если в игре появится реклама или аналитика — обнови политику **до** выпуска такой версии.
